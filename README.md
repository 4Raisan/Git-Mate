# Git-Mate

An early Python desktop experiment for managing Git history. The repository includes the prototype script and GUI sketches.

Read `Git-Mate.py` before trying it. Use a disposable local repository when experimenting with history changes.

## Try the prototype

Create a disposable repository with `git init git-mate-demo`. Start the GUI with `python Git-Mate.py` and enter the absolute path to that folder. Confirmation checks whether the folder exists. Undo updates the interface and its counter. Git commands in the current source are comments.
